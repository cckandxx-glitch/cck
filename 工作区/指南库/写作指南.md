# 写作指南

> 来源：2026-10-06 吹膜机 LinkedIn 文章对比（我的版本 vs 客户版本）的复盘。
> 以后写任何文章、文案、白皮书、帖子之前，先读这份指南，写完过一遍第 6 条自检清单。

## 1. 准确第一（可信度的灵魂）
- 不做绝对化表述。
  ✗ "低于 0.025mm 就必须用多层共挤"
  ✓ "单层可以吹到 0.025 以下，只是稳定性难保证；需要 EVOH/阻隔层时单层做不到"
- 每个估算都要带前提："减薄 10–20% 取决于产品结构和材料选择，不能默认所有应用都成立"。
- 参数先查（知识库 / CRM 产品表 / 官网），查不到就说查不到，不编。
- 卖点必须和实际配置一致：配了自动口模，就不能写"需要更换口模唇径"——自己打自己。

## 2. 数字是钩子，但要诚实
- 能给具体数字就给具体数字："一年省 20–30 吨树脂"比 "meaningful savings" 有记忆点得多。
- 但严谨不能把说服力稀释光：数字后面跟一句前提（估算、基于 X 产量），不要一路对冲到没有信息量。
- 真实参数（如永磁电机省电 15%）优先用；估算的数字要明确是估算。

## 3. 对竞品公平——公平是最好的推销
- 不踩单层抬共挤；把问题归因到"离线复卷工序"，而不是"单层机本身"。
- 诚实承认对方优势（单层便宜、灵活、换料快）——读者因此更信你对自家产品的评价。
- 主动提买家该算的成本（备品口模库存、试产损耗等），不只说好处。

## 4. 语气匹配渠道
- LinkedIn / 社媒：聊天式语气、短句，"Let's face the numbers"、"Basically" 这类口语化钩子，完读率优先。
- 白皮书 / URS / 官网：正式、完整、带限定语。
- 仿参考文章时，仿骨架（结构、节奏），不照抄词汇。

## 5. 结构（已验证的 LinkedIn 骨架）
1. 开头钩子：一次真实讨论 + 一个客户痛点问题（URS / 怎么选）
2. 打破迷思："很多人以为 X 更省钱，但……"
3. "Let's face the numbers"——用具体数字说话
4. 分主题小标题：换料 → 省料 → 污染 → 品控
5. 灵活性 vs 速度：给两类买家两类答案（低速高灵活选 A，高速选 B）
6. 结尾 CTA："不确定你需要哪种？来聊"

## 6. 写作前：调用行业弹药
- 写吹膜机/制袋机相关文章前，先查 `行业研究笔记.md`（市场数据、层数演进、应用、材料、技术趋势、竞争格局、LinkedIn 打法）。
- 第三方市场数字当背景用，别当自家参数；自家参数以 CRM 产品表/官网为准。
- 行业笔记会持续更新，写之前扫一眼有没有新东西。
