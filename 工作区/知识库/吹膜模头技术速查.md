# 吹膜模头技术速查（自学沉淀 2026-10-06 第 4 轮）

> 来源：搜狐《吹膜配方及工艺笔记——多层共挤吹膜设备关键技术》、PLASTAR 模头选型指南、Polydynamics《Blown Film Dies》、各厂产品页（春秋/瑞泓/华瑞/力风等）、专利。
> 用途：客户问"模头什么结构"、URS 技术规格、LinkedIn 技术帖素材。

## 一、模头三大流派（客户问"你们模头什么结构"时）

### 1. 平面叠加型（Stacked，代表：加拿大 Brampton Engineering）
- 侧进料，熔体以中心轴线对称，在每层的**叠加面**流动（非筒状）。
- 优点：层数可任意组合、结构简单、**每层温度单独控制**（防物料分解）、层数变化不影响机头内外径。
- 缺点：流道在平面/斜面上，熔体压力无法平衡，密封困难，需要许多螺钉密封。

### 2. 锥形叠加型（代表：加拿大 Macro）
- 单元化短锥形模块，流道在锥形圆柱面上；本体强度高、承压更高、密封更好。
- **上斜锥形**（Macro）：每层由下到上斜面叠加、相互吻合不易溢料，一次分流，适合小直径（10–50mm）。
- **下斜锥形**（Macro 专利）：由上到下斜面叠加，底部同平面侧进料一次分流，减少熔体停滞、易清洗、厚度分布好；每层流道数量不受限（16 条以上螺旋流道）。

### 3. 径向/螺旋芯棒型（代表：Battenfeld Gloucester，9 层模头）
- 螺旋芯棒式流道，流体在圆柱面上；**低中心设计，模头高度不随层数增加而增大**。
- 熔体压力在流道圆周方向平衡，**密封比叠加型好**。
- 缺点：熔体温度不能单独控制（尤其中间层）。

### 螺旋流道工作原理（写技术帖的核心）
- 熔体从中心进料孔进入 → 分成 8 股（或 16 股）→ 进入螺槽起点 → 每股再分成两股：轴向料流 q2（环形间隙）+ 螺旋料流 q3（螺旋槽）。
- 沿挤出方向 q3 越来越少、q2 越来越多 → 螺旋流连续过渡到轴向流 → 充分混合 → 口模圆周方向压力/温度/速度均匀 → 薄膜厚度均匀。
- **流道四参数**：螺旋角 Φ、锲角 β、螺旋消退角 ψ、初始面积 A。
- 理想状态：螺旋流 q3 刚好在流道结束时全部转为轴向流；过早结束或末端还有螺旋流 → 口模速度不均 → 厚薄不均。
- 国外设计方法：经验 + 理论计算（POLYFLOW、FLOW2000 等 CFD 软件），算压力分布/停留时间/剪切速率/末端速度分布；多层模头每层按该层材料参数和产量单独计算。

## 二、进料方式对比
| 方式 | 特点 | 适用 |
|---|---|---|
| 侧进料（Side-fed） | 结构简单、便宜；熔体分布可能不均 | 单层、厚度公差要求不严 |
| 中心/底部进料 | 复杂但熔体流动和温度分布更均匀、厚度控制更好 | 多层共挤、高性能膜 |
| 螺旋芯棒 | 最主流高质量方案：多次分流汇合、消除熔接线、厚度公差极佳 | 多层共挤、苛刻应用 |

## 三、模头材料与表面处理（谈"耐用"时）
- 模体：42CrMo 合金钢（强度/韧性/尺寸稳定），锻造后**自然时效半年**消除内应力，五轴联动精加工。
- 熔体接触面：**镀铬 + 镜面抛光**（硬度、耐磨、耐蚀、减少粘附停滞，易清洗）；模体淬火+去应力。
- 口径：同等工况下处理过的模头寿命比常规加工**延长最多 40%**（PLASTAR 口径）。
- 流道设计目标：减少压力波动、消除停滞区（防聚合物降解）；CFD 仿真验证。
- 春秋模头卖点口径：换料时极短流道降低原料损失、低压力水平带来高产量、紧凑设计低净空易进出、树脂接触面全部涂覆、自清洁。

## 四、旋转模头 vs 水平摆动牵引（国产主流方案）
- **旋转模头**：模头整体旋转。问题：流道长、熔体密封难、漏料、维护难。
- **水平摆动牵引**（±180°/±360° 摆动式旋转牵引）：牵引系统旋转取代模头旋转 → 简化模头结构、彻底解决旋转模头密封/漏料/维护难题、克服膜卷大小头/松紧边、保证平整度、节能易维护（华瑞/力风/超新/拉新业/瑞泓等厂通用口径）。
- 配置实例（瑞泓 3 层共挤旋转模头吹膜机）：旋转模头 600–2500mm + 固定模头 3000mm、双收卷、压花辊 600–800mm、插边器选配、自动吸料/冷风机/快速换网（液压）。
- 叠加模头各层独立加热并容纳隔热介质 → 适合温差大的塑料膜；流道分布均匀 → 流体稳定+厚度均匀（百度百科"三至七层共挤牵引旋转吹膜机组"）。

## 五、自动口模/膜口间隙自动调整
- **专利 CN217319299U**：膜口间隙自动调整装置——膜口调节执行单元 = 膜口间隙调节机构 + 执行电器；不同类型吹膜机膜口结构不同，对应不同调节机构和电器。
- **模唇调节传统方式**（政钰机械）：调整螺丝，靠模具钢材弹性 + 螺丝施力改变开口间距；"只压不拉"和"可压可拉"两种结构。
- 柔性唇径（自动口模）价值：不停机/少停机换幅宽，减少换料头时间，快速切换产品规格——对多品种小批量客户是硬卖点。

## 六、模头与 IBC 的配合
- IBC 内冷 + 外风环同时冷却：缩短冷却定型时间 → 更高线速产量；冷却均匀稳定 → 膜泡稳定、清晰度好、雾度低；膜泡稳定 → 厚度均匀性更好。
- 模头流道均匀性是 IBC 发挥效果的前提（流道不均，内冷再强也救不回来）。
