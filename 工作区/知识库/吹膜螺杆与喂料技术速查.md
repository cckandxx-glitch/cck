# 吹膜螺杆与喂料技术速查（自学沉淀 2026-10-06 第 7 轮）

> 用途：客户问"螺杆什么材质/喂料什么方案"、URS 规格、LinkedIn 技术帖素材。

## 一、螺杆类型（谈"塑化质量"时）

### 屏障螺杆（Barrier Screw，多层线支撑层标配）
- **结构**：熔融段 Barrier 副螺纹把螺槽分成**固体床 + 熔体床**；固体床宽度深度逐渐变小，熔体床逐渐变大，最终过渡到计量段。
- **塑化机理**：固体床体积缩小保证排气（不像单螺杆靠压缩比排气体）；固体床直接贴机筒吸热 + 强剪切 → 塑化好、熔体温度低；熔体床剪切变小 → 温度不再继续升。
- **优点**：
  1. **适应性广**：美国 XALOY 称其通用型螺杆除 PVC 外可加工大多数塑料。
  2. **产量大**：压缩比失去意义，塑化靠固体床传热+强剪切；计量段可设计很深 → 高产量。例：Battenfeld 65 分离型螺杆加工聚烯烃，加料段 H1=12.62mm、计量段 H3=9.6mm，螺槽体积比 1.5126——传统单螺杆不可能塑化好。
- **设计难点**：副螺棱与机筒间隙（变化中，要保证熔体以合适速度过到熔体床）；副螺棱导程与固体床深度变化匹配（固体床体积缩小量 > 料体积 → 卡料；< 料体积 → 床内有熔体影响塑化）。
- **现状**：熔融过程方程变量太多无完美分析软件，设计靠经验 + 一定范围内符合熔融过程即为好螺杆。
- **计量段加混炼元件**：保证混炼混色效果（国外设备典型配置）。

### 膜类机筒螺杆配置（金纬口径）
- 膜类产品机筒用**分离型与屏障型螺杆**，计量段将未完全熔融固体与充分塑化熔体完全分离。

## 二、螺杆表面/材质（谈"耐用"时）
| 方案 | 寿命口径 | 说明 |
|---|---|---|
| 38CrMoAlA 氮化钢螺杆头 | **1–2 年** | 氮化层硬度 HRC62–68、硬度层 0.3–0.6mm，耐磨 |
| 双金属合金 | **3–5 年** | 基体韧 + 表面硬，耐磨耐蚀，高端线标配 |
| 自清洁设计 | — | 高度抛光+镀膜，高速高压冲刷使每个流道自清洁，减少换料浪费和停机维护（奥翔口径） |

- **挤出压力指标**：普通 PE 膜 15–25MPa；高压精密膜更高。压力稳定是产量和厚度稳定的基础（爱采购百科）。

## 三、喂料系统（多层线核心卖点）

### 失重式（重量式/Gravimetric）喂料 vs 体积式喂料
| 维度 | 失重式 | 体积式 |
|---|---|---|
| 原理 | 称重料斗 + 计量装置 + 搅拌装置，PLC+变频器控螺杆输出量，按重量/速度配料，**自校准** | 按速度中的体积喂料，无称重反馈 |
| 精度 | **0.25%–1%**（双螺杆失重式可达 **±0.5%**） | 1%–5%（够用场景） |
| 动态要求 | 高动态高精度称重系统检测 1–5 秒内出口流量 | 低 |
| 适用 | 多层共挤各层配比精确控制、色母/添加剂、EVOH 等贵重料 | 单层、对配比不敏感 |
| 附加价值 | 系统密封减污染；减轻工人劳动强度；**实时树脂消耗追踪**（接 AI/能效趋势） | 便宜、结构简 |

- **精度描述规范**（松耐）：用**重复精度 + 线性精度**（基于数学统计学标准方差和均值）描述，不是单一数字。
- **影响精度的 5 个坑**（cmpe360）：称重系统动态精度、螺杆选型、料性（流动性/架桥）、传感器位置、控制周期。
- **科倍隆**：SFT 重量传感器是失重式喂料核心；K4G 混料站；智能皮带式轻柔散料处理。

### 为什么多层线必须失重式
- 层厚比 = 各层喂料比，配比飘 → 层厚飘 → 阻隔性能飘（EVOH 层薄了透氧升几个数量级）。
- EVOH 贵重，体积式浪费大；失重式自校准 + 消耗追踪 = 成本可控。
- 失重式计量加料反馈还能消除约 2/3 纵向厚度偏差（接 AGC 慢环，见测厚速查表）。

## 四、EVOH 共挤与防架桥（客户问"EVOH 线怎么配"时）
- **EVOH 特性**：乙烯-乙烯醇共聚物，顶级阻氧，几微米厚把透氧降几个数量级；对水敏感（吸湿后阻氧下降）、加工温区窄。
- **典型结构**：5 层对称 PE/Tie/EVOH/Tie/PE（牛奶膜、小食品）；7 层 EVOH 可压缩装入两个相邻 PE 层间、外层 PE 保护（降 EVOH 用量）；PA/EVOH/PE 用于肉品/饮料/带骨刺产品。
- **架桥问题**：EVOH 粒子细、易吸湿结块 → 料斗内架桥断料 → 层厚波动甚至断层。
- **防架桥/喂料对策**：
  1. **失重式喂料**（核心）：连续计量 + 断料即时报警，比体积式抗架桥强。
  2. 喂料螺杆 + 搅拌装置（失重式三件套之一）防结块。
  3. 料斗干燥/除湿（EVOH 吸湿敏感）。
  4. 系统密封（失重式自带）减污染减吸湿。
  5. 窄温区精确控温 + 专用螺杆（接可降解/阻隔材料趋势）。
- **青贮膜场景**（Viaflex）：PE+EVOH 薄型阻氧膜常需加第二层抗 UV 保护层；共挤黑底白板（PE 层间夹 EVOH）做单层板材方案。

## 五、给客户的一句话话术
- "支撑层用屏障螺杆：固体床贴筒吸热+强剪切，塑化好温度低，计量段深所以产量大——国产线产量上不去，多半输在螺杆。"
- "螺杆头 38CrMoAlA 氮化 1–2 年、双金属 3–5 年；自清洁流道抛光镀膜，换料少浪费。"
- "多层线喂料必须失重式：精度 0.25–1%，层厚比才稳，EVOH 层不飘，阻隔才不飘。"
- "EVOH 怕架桥：失重式连续计量+搅拌+除湿+密封，断料秒报警。"
- "失重式喂料还送一个隐藏价值：实时树脂消耗追踪，能耗和成本都看得见。"
